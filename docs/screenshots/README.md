# Screenshots

Drop real captures of the running dashboard here so the root README and docs render images.
Suggested set (referenced elsewhere in the docs):

- `overview.png` — the overview: workflow list with health badges, live budget, chat box
- `incidents.png` — the incident feed with a proposed patch awaiting approval
- `workflow-detail.png` — a workflow's run timeline + version log
- `costs.png` — daily LLM spend against the hard budget, broken down by service

Fastest way to capture them: run the dashboard (`cd dashboard && npm run dev`, which starts in
demo mode) and screenshot each surface at ~1440px wide.
